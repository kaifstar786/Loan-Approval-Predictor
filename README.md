## Project Overview
This project uses Machine Learning to predict the likelihood of loan approval using sample dummy data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Logistic Regression

## Project Scope
- Create a sample loan dataset.
- Analyze income, loan amount, credit history, and employment.
- Train a Logistic Regression model.
- Evaluate model performance.
- Visualize loan approval distribution.
- Make a sample prediction.

## Project Files
- `main.py` – Main Python source code.
- `loan_data.csv` – Sample dataset.
- `loan_approval_chart.png` – Visualization.

## Disclaimer
This is an educational project using synthetic dummy data. It is not intended for real loan approval decisions.
